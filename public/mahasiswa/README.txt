# Direktori Foto Resmi Mahasiswa Informatika 2023 Universitas Alma Ata

Simpan foto mahasiswa di folder ini dengan format nama berkas sesuai NIM masing-masing:
Contoh:
- 233200262.jpg (Fajar Maulana)
- 233200299.jpg (Yazid Syafrudin)

Jika file foto tersedia di folder ini, aplikasi web akan langsung otomatis memuat dan menampilkannya pada kartu mahasiswa di halaman "Tentang Kami".
Jika foto belum diunggah, kartu mahasiswa secara cerdas menampilkan avatar siluet Jas Almamater Alma Ata yang rapi dan elegan.
